# Profile Decoder

**Control System XML Translator** — a browser-based tool that decodes and translates control system profile XML.

Open it in **Google Chrome** (or any modern browser). No install required.

## Live demo

After GitHub Pages is enabled:

`https://<your-github-username>.github.io/profile-decoder/`

## Run locally

1. Double-click `index.html`, **or**
2. Drag it into a Chrome window, **or**
3. From Terminal:

```bash
open -a "Google Chrome" index.html
```
